# 藍帶檸檬海綿蛋糕挑戰賽 | Le Cordon Bleu Lemon Sponge Cake Challenge

> 本專案為大學期末專案作品：結合法式藍帶廚藝學院（Le Cordon Bleu）烘焙科學與多重結局體驗的互動式網頁烘焙模擬小遊戲。

🔗 **線上遊玩連結 (GitHub Pages)**：[點此立即進入烘焙工坊](https://alpacamymac.github.io/cordon-bleu-lemon-sponge-cake/)

## 專案亮點與核心特色

1. **食譜份量換算考驗**：
   - 開局展示藍帶標準「10 人份」經典檸檬海綿蛋糕食譜。
   - 玩家可自訂目標製作人數（1人份、2人份、5人份、10人份），考驗玩家是否能細心自行將各項原料等比例除算。若選了少人份卻直接照抄 10 人份的巨大克數，出爐時將揭曉搞笑的「大胃王豬豬 🐷」結局！

2. **精準線性烘焙互動關卡**：
   - **電子秤精準測重**：7 種原料測量、Tare 歸零功能、微調按鈕、低筋/中筋/高筋麵粉筋度選擇。
   - **融化無鹽奶油**：溫水加熱溫控，避免高溫焦化或低溫未融。
   - **全蛋隔水打發**：打發至鵝黃色緞帶狀，並監控升溫速率，防止蛋液熟化消泡。
   - **粉類過篩與 J 字切拌**：網篩落粉與限制切拌次數，防止麵筋過度緊繃。
   - **模具抹平與鋪紙**：以刮刀調整表面平整度，確保受熱均勻。
   - **烤箱預熱與溫控**：設定 180°C 預熱、烘烤溫度與時間微調。

3. **六大主結局與全步驟藍帶科學診斷報告**：
   - 根據操作數據計算失誤嚴重度，揭曉 6 大專屬動態蛋糕插畫（👑 完美蛋糕、🐷 吃成豬豬、💥 表面裂開、🔥 邊緣焦黑、🧱 組織乾硬、📐 形狀歪斜）。
   - 提供條列式科學診斷報告，詳細解析蛋白質變性、麵筋鏈結、焦糖化反應與熱對流等物理化學原理。

4. **期末展示 Demo 輔助模式**：
   - 頂部導覽列提供快捷選單：支援「⚡ 一鍵填入精準換算克數」與「🍰 一鍵直達 6 大結局」，方便課堂發表與評審快速檢閱所有分支路徑。

## 技術棧

- **核心框架**：React 18 + Vite
- **程式語言**：TypeScript (嚴格型別定義)
- **樣式與動畫**：Tailwind CSS + 自訂 Keyframes 動畫
- **視覺插畫**：自製模組化向量動態 SVG (零失真 4K 縮放)
- **音效系統**：Web Audio API 純原生合成器 (零外部音檔依賴，內建容錯保護)
- **部署平台**：GitHub Pages (GitHub Actions 自動化 CI/CD)
